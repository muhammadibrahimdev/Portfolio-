# Project screenshots

Drop images into the folder for each project. Name them `1.png`, `2.png`, `3.png`, `4.png`
(up to four per project). They appear automatically in the project card and on the project page,
and the card rotates through them every few seconds. Missing files are skipped.

public/projects/ai-questions-answers-generator/
public/projects/ai-multilingual-messenger/
public/projects/sellkar-storefronts/

Tips:
- Desktop screenshots: about 1600 x 1000 px (16:10), under 400 KB each.
- Mobile app screenshots (Messenger): portrait phone screenshots are fine; they are shown whole, not cropped.
- To use .jpg or .webp instead, change the file names in the `images` list in lib/data.ts.
- `resume.pdf` in this folder is the file behind the Download CV buttons.
